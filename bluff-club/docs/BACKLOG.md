# Future backlog (not in v1)

Nothing here is implemented or advertised as available.

- **WRONG QUESTION mode (idea only).** Everyone answers the same question, except one
  player, who secretly gets a slightly different question. Answers are revealed
  together, and the group hunts for the odd one out. This needs its own content
  format (question pairs) and a different reveal and answer flow. It must not reuse
  "Find the Bluffer" scoring without playtesting.
- More packs, each with its own entitlement and **not** included in the launch Party
  Bundle unless explicitly decided and communicated.
- Optional "bluffer gets a vague category hint" variant, if playtests show the
  bluffer loses too often.
- Custom word lists created on-device (would need moderation and privacy thought).
- Localisation (Afrikaans, isiZulu, isiXhosa…) with native-speaker content, not
  machine translation.
- Prorated bundle upgrade, if Play/RevenueCat tooling makes it simple and honest.
- iOS build (Capacitor + RevenueCat iOS; Apple non-consumable product setup).
- Larger-text "projector mode" for the discussion timer on tablets.
